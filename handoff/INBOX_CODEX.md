## 要解决的问题
当前详情页与 demo 差距最大。demo 是经典三栏阅读布局，用户明确喜欢；现版把左侧章节导航做成了下拉、阅读版式较朴素。本步恢复三栏骨架 + 舒适长文阅读。

## 范围（只动 apps/web，对照 docs/prototype）
1. **三栏布局骨架**：
   - 左：**C01–C0x 常驻章节导航侧栏**（每项：编号 + 标题 + 段落范围/字数，当前块高亮、点击滚动定位）。这是重点——替代当前下拉为常驻侧栏（顶部章节下拉可保留为辅助，但不能取代左侧常驻栏）。
   - 中：正文阅读区。
   - 右：资源入口（知识卡片/作文素材/复核 的入口或抽屉触发，**本步只做入口和容器，不做联动细节**）。
2. **长文阅读版式**：参照 demo `styles.css` 调正文最大宽度、字号、行距、段距、标题层级，达到舒适长文阅读。
3. **标题区规范**：标题格式化为"课程：{课程名} ｜ 讲师：{讲师}"，下面副标题/课型/原始文件名/字数比例分层；**长标题必须折行不撑破首屏**。
4. **数据真实性**：标题、讲师、课型、状态、四档字数比例都用 API 真实字段，正确显示。

## 验收标准
- 详情页呈现稳定三栏：左常驻 C 段导航、中阅读、右资源入口。
- 左侧章节项点击能定位到正文对应段落；当前阅读块高亮。
- 长标题（如"五上-人文综合涵养-寒假-第三讲-隐显-偷钱+第四讲-文言文-醉叟传1"）不撑破布局。
- 正文阅读宽度/行距接近 demo，读着舒适。
- 真实课程（醉叟传实验02 / 寒假第七讲实验02）四档字数比例、标题、讲师正确。
- `cd apps/web && npm run check` + `npm run build` 通过。
