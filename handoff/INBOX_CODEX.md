## 范围（只动 apps/web，行为参照 docs/prototype）
1. **四档版本切换体验**
   - 保真清洗/精简整理/学习整理/结构提纲 四档 tab 切换流畅；切换时尽量**保持当前阅读位置/章节**，不要每次跳回顶部。
   - 各档下，左侧 C 段导航、段间导航仍可用。
2. **原文对照分块同步（重点，对照 demo）**
   - 点"对照原文"进入对照视图：**左栏=原始转写稿的当前 C 段，右栏=当前选中版本的同一 C 段**，左右是**同一分块**，量级对等、不整篇错位。
   - 切换 C 段（左侧章节栏或段间导航）时，左右两栏同步切到同一块。
   - 退出对照回到正常阅读。
   - 数据来源：左栏原文用 `paragraphs` 里该 chunk 的 `paragraph_range` 对应段落；右栏用当前版本对应该 chunk 的内容（若版本正文按 chunk 分节渲染，则取对应节）。**只用真实 API 数据，不硬编码。**
   - 若 API 现有字段不足以做到精确分块对照（例如版本正文无 chunk 锚点），**在 OUTBOX 写明"需要后端补 XX 字段"，先用现有字段做到最接近的同段对照**，不要改后端、不要造假数据。
