# TextCore / 文心 前端页面结构与跳转关系 v0.1

> 用途：指导下一步高保真可点击 HTML 原型制作。
> 范围：只定义前端原型页面、功能区域、层级关系和跳转逻辑；不定义真实后端、AI 处理、Word 解析实现。

## 1. 原型目标

本阶段目标是把设计师提供的视觉方向扩展为一个可点击的高保真 HTML 原型，用假数据模拟完整产品体验。

原型需要验证：

- 首页工作台是否易懂。
- 课稿列表是否方便回看历史结果。
- 课程详情页是否适合长文阅读。
- 三个版本切换是否自然。
- 原文对照、知识卡片、作文素材是否放在合适的位置。
- 知识资产库是否应该作为独立一级页面存在。
- 导出 Word 流程是否清楚。

## 3. 一级页面

### 3.1 工作台

参考图：`textcore_homepage_hifi.png`

定位：

工作台是用户进入文心后的默认页面。它不是营销首页，而是一个本地文档处理工作台。

核心功能：

- 上传课堂转写 Word。
- 查看当前处理进度。
- 查看最近处理历史。
- 快速进入课程详情页。

页面结构：

```text
顶部导航
├── Logo：文心 TextCore
├── 导航：工作台 / 课稿列表 / 知识资产库
└── 状态：本地运行中

主体区域
├── 左侧：上传卡片
│   ├── 拖拽上传区
│   ├── 选择文件按钮
│   └── 支持说明：Word，最多 1-5 篇
│
└── 右侧：处理进度与历史记录
    ├── 当前处理进度
    ├── 步骤列表
    └── 最近处理表格
```

主要交互：

- 点击导航“课稿列表”进入课稿列表页。
- 点击导航“知识资产库”进入知识资产库页。
- 点击上传区，弹出本地文件选择。原型中不需要真实上传，只模拟进入处理中状态。
- 点击“查看整理结果”，进入课程详情页。

原型状态：

- 空状态：没有文件时显示上传引导。
- 处理中：显示步骤进度。
- 已完成：历史记录中显示“查看整理结果”。

### 3.2 课稿列表

参考图：`detailspage_hifi.png` 的导航风格，列表页可参考设计师新版 `listpage_hifi.png`。

定位：

课稿列表用于管理已处理和处理中课程，是从“每周处理”走向“长期回看”的入口。

核心功能：

- 查看所有课程处理记录。
- 通过课型、状态、关键词筛选。
- 进入课程详情页。
- 从列表直接导出 Word。

页面结构：

```text
顶部导航
├── Logo
├── 工作台 / 课稿列表 / 知识资产库
└── 本地运行中

页面标题区
├── 标题：课稿列表
├── 简短说明
└── 新建上传按钮

筛选区
├── 搜索框
├── 课型筛选：全部 / 阅读理解 / 作文点评 / 文言文 / 古诗词 / 混合课
└── 状态筛选：全部 / 处理中 / 已完成 / 有复核

课程表格
├── 课程名
├── 课型
├── 处理状态
├── 更新时间
├── 复核标记数量
└── 操作：查看 / 导出
```

主要交互：

- 点击课程名或“查看”，进入课程详情页。
- 点击“导出”，打开导出 Word 弹窗。
- 点击“新建上传”，回到工作台上传区。
- 筛选和搜索在原型中只做视觉状态，不需要真实过滤。

### 3.3 知识资产库

参考图：`assetspage_hifi.png`

定位：

知识资产库展示从课程中提取出来的方法卡片、素材和词汇。它不是完整知网，但可以作为文心内部的轻量知识沉淀区。

核心功能：

- 浏览方法卡片。
- 浏览词汇生词。
- 浏览佳句素材。
- 进入卡片详情。
- 从卡片反查来源课程。

页面结构：

```text
顶部导航
├── Logo
├── 工作台 / 课稿列表 / 知识资产库
└── 本地运行中

页面标题区
└── 标题：知识资产库

二级 Tab
├── 方法卡片库
├── 词汇生词本
└── 佳句素材册

卡片网格
├── 卡片标题
├── 标签
├── 详解
├── 关键重点
└── 来源课程
```

主要交互：

- 点击二级 Tab 切换资产类型。
- 点击卡片进入卡片详情抽屉或详情页。
- 点击来源课程进入课程详情页。

## 4. 二级页面 / 子页面

### 4.1 课程详情页

参考图：`detailspage_hifi.png`

定位：

课程详情页是文心第一版最核心的页面，用于阅读整理结果、查看知识卡片、查看作文素材、导出 Word。

页面结构：

```text
顶部导航
├── Logo
├── 工作台 / 课稿列表 / 知识资产库
└── 本地运行中

课程标题区
├── 课程名：五上寒假第七讲
├── 讲师：张老师 / 陈老师
├── 课型：阅读理解 + 作文点评
└── 操作：导出 Word

主体
├── 左侧 / 中央：正文阅读面板
│   ├── 版本 Tab：保真清洗版 / 学习整理版 / 结构提纲版
│   ├── 原文对照开关
│   ├── 课程摘要
│   ├── 正文内容
│   └── 文中复核标记
│
└── 右侧：辅助信息栏
    ├── 知识卡片
    ├── 作文素材
    └── 复核列表
```

主要交互：

- 点击“保真清洗版 / 学习整理版 / 结构提纲版”切换正文内容。
- 默认选中“学习整理版”。
- 点击“原文对照”展开对照模式。
- 点击右侧知识卡片，打开卡片详情。
- 点击作文素材，打开素材详情。
- 点击“导出 Word”，打开导出弹窗。

### 4.2 原文对照模式

定位：

用于检查 AI 整理效果。默认不显示，点击后进入。

页面结构：

```text
课程详情页
└── 原文对照模式
    ├── 左栏：原始转写稿
    ├── 右栏：当前整理版本
    ├── 顶部：退出对照
    └── 右侧：复核标记列表
```

原型要求：

- 第一版不需要段落精确映射。
- 只需要展示左右对照的视觉和切换关系。
- 对照模式不作为默认入口。

### 4.3 导出 Word 弹窗

定位：

导出简洁可打印材料。

页面结构：

```text
导出 Word
├── 选择导出内容
│   ├── 课程摘要
│   ├── 学习整理版
│   ├── 保真清洗版
│   ├── 结构提纲版
│   ├── 知识卡片
│   ├── 作文素材
│   └── 复核标记
│
├── 版式
│   ├── 简洁可打印
│   └── 完整留档
│
└── 操作
    ├── 取消
    └── 导出 Word
```

默认勾选：

- 课程摘要。
- 学习整理版。
- 知识卡片。
- 作文素材。
- 复核标记。

### 4.4 卡片详情

入口：

- 课程详情页右侧知识卡片。
- 知识资产库卡片网格。

展示方式：

第一版建议用右侧抽屉，不单独跳转整页。

内容结构：

```text
卡片详情
├── 标题
├── 类型
├── 详解
├── 关键重点
├── 课堂例子
├── 来源课程
└── 操作：复制 / 查看来源课程
```

### 4.5 作文素材详情

入口：

- 课程详情页右侧作文素材。
- 知识资产库佳句素材册。

展示方式：

第一版建议用右侧抽屉或弹层。

内容结构：

```text
作文素材详情
├── 素材标题
├── 主题标签
├── 可用角度
├── 可模仿表达
├── 反面表达
├── 来源课程
└── 操作：复制 / 查看来源课程
```

## 5. 三级状态与局部组件

### 5.1 处理步骤组件

用于工作台。

状态：

- 未开始。
- 解析 Word。
- 识别课程信息。
- 清洗口语稿。
- 生成学习整理版。
- 提取知识卡片。
- 生成作文素材。
- 整理完成。

### 5.2 复核标记组件

用于课程详情正文和右侧栏。

状态：

- 文中灰色弱标记。
- 右侧复核列表。
- 点击复核项后滚动到正文对应位置。

### 5.3 本地运行状态

位置：

顶部导航右侧。

状态：

- 本地运行中。
- 正在处理。
- 处理完成。
- 离线。

第一版只做视觉状态。

## 6. 页面跳转关系

```text
工作台
├── 上传文件 → 处理中状态 → 课程详情页
├── 最近处理“查看整理结果” → 课程详情页
├── 顶部“课稿列表” → 课稿列表
└── 顶部“知识资产库” → 知识资产库

课稿列表
├── 查看 → 课程详情页
├── 导出 → 导出 Word 弹窗
├── 新建上传 → 工作台
└── 顶部“知识资产库” → 知识资产库

课程详情页
├── 版本 Tab → 当前页局部切换
├── 原文对照开关 → 原文对照模式
├── 知识卡片 → 卡片详情抽屉
├── 作文素材 → 作文素材详情抽屉
├── 导出 Word → 导出弹窗
├── 返回工作台 → 工作台
└── 顶部“课稿列表” → 课稿列表

知识资产库
├── 方法卡片库 / 词汇生词本 / 佳句素材册 → 当前页局部切换
├── 卡片 → 卡片详情抽屉
├── 来源课程 → 课程详情页
└── 顶部“工作台” → 工作台
```

## 7. 原型第一版页面清单

高保真 HTML 原型第一版建议实现以下页面和状态：

1. 工作台。
2. 课稿列表。
3. 课程详情页。
4. 知识资产库。
5. 原文对照模式。
6. 导出 Word 弹窗。
7. 卡片详情抽屉。
8. 作文素材详情抽屉。

其中 1 到 4 是页面级路由，5 到 8 是页面内交互状态。

## 8. 原型不实现的内容

- 不接真实 Word 上传。
- 不接真实 AI。
- 不做真实导出。
- 不做登录和权限。
- 不做云端同步。
- 不做知网真实接入。
- 不做复杂知识图谱。

## 9. 前端路由建议

如果用静态 HTML 原型：

```text
index.html                 工作台
courses.html               课稿列表
course-detail.html          课程详情
assets.html                知识资产库
```

页面内用 JavaScript 模拟：

- Tab 切换。
- 原文对照展开。
- 导出弹窗。
- 抽屉打开关闭。
- 处理步骤状态。

如果用 React/Vite 原型：

```text
/                         工作台
/courses                  课稿列表
/courses/:id              课程详情
/assets                   知识资产库
```

本阶段建议先用静态 HTML/CSS/JS，便于快速发布到 GitHub Pages。
