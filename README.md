## 讨论重点

- 首页是否像一个轻工作台，而不是上传工具或后台系统。
- 结果页是否阅读优先，长文阅读是否舒服。
- 知识卡片和作文素材放右侧是否合适。
- 原文对照默认收起、点击展开是否符合使用习惯。
- Word 导出是否应以“简洁可打印材料”为主。
