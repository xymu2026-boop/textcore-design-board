# Essay Feedback Preservation Rules

- Preserve the chain: original student sentence, teacher-identified problem, revision direction, and transferable writing method.
- Do not compress essay feedback so far that the teacher's judgment or reasoning disappears.
- Keep student wording when it is the object of critique. If exact wording is uncertain, mark it in `review_flags`.
- Separate local fixes from reusable methods. A single sentence edit should not be presented as a universal rule unless the teacher made that connection.
- Preserve high-value examples, usable expressions, theme links, and teacher comments for later writing-material extraction.
