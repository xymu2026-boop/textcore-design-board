Codex 低保真方向

这组图是 Codex 生成的两个低保真方向，用于比较“轻工作台 + 阅读主栏”和“资料台 + 分屏检查”的差异。

方向一：轻工作台 + 阅读主栏

首页上传和历史平衡，结果页以学习整理版为主，右侧放卡片、素材和复核。

推荐方向阅读优先

方向二：资料台 + 分屏检查

更偏检查和调试，原文与整理稿并排，适合早期验证 AI 处理效果。

对照模式检查优先

手机讨论时先看这几件事

首页像不像工作台

上传入口不要太大，历史记录要能快速进入结果页。重点判断它是轻松的工具，还是变成了后台。

结果页能不能长时间阅读

正文是主角。右侧卡片、作文素材和复核标记应该辅助阅读，而不是抢注意力。

原文对照放在哪里

默认不显示原文，需要检查时再展开。早期可以保留强对照模式，方便看 AI 是否漏内容。
